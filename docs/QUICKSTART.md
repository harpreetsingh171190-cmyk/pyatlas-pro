# Quickstart

## Open the portable app

1. Extract the ZIP and open the `PyAtlas-Pro` folder.
2. Open `dist/index.html` in your browser. The interface is English-only.
3. Search the catalogue, bookmark projects, and compare up to three tools.
4. Select bulk checkboxes, then use **Stack Builder** to draft dependencies.
5. Use **Learning paths** for ordered practice and locally saved progress.

The catalogue and workspace work offline. External project links and optional
**Check GitHub now** requests require internet access.

## Install as an app

```sh
python -m pyatlas serve
```

Open `http://localhost:8765`, wait for **Offline cache ready**, and use the browser's
Install option. Phone installation requires HTTPS hosting or a local environment
on the phone; another computer's localhost is not the phone's localhost.

## Preserve your work

Use **Backup** or **Secure backup** for project workspace data. Learning progress
and usage counts have separate exports in their own panels. Browser data can be
cleared by the browser or OS, so keep downloaded backups somewhere safe.

## Shortcuts

- `/`: focus search when outside input fields.
- Ctrl+K / Cmd+K: open the command palette.
- Escape: close a dialog.
- Tab and Shift+Tab: navigate controls.
