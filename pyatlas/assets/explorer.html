Dependency Compatibility, Security & Licenses

Offline checks validate package names and conflicting exact pins. Online checks contact PyPI and OSV only when you press the online button. Unpinned names check the latest version, not an installed environment.

Full dependency resolver
The browser checks Requires-Python metadata, not transitive dependency conflicts. Export requirements, then run the following command using the Python interpreter and OS you intend to use. It uses pip's binary-only dry run; no packages are installed.
python -m pyatlas inspect --requirements requirements.txt --online --output audit.json
Install the optional tooling first with: python -m pip install ".[audit]"
