# Attribution and independent adaptation

PyAtlas Pro is a newly written application built around catalogue content from Vinta Chen and Awesome Python contributors. It is independent of the upstream maintainers.

The uploaded source LICENSE says CC BY 4.0; the source pyproject metadata says MIT. This adaptation follows the explicit source LICENSE for imported content and does not copy the upstream website implementation. New code has a separate MIT licence. The original catalogue and attribution remain visible; rebranding does not erase authorship.

The upstream assistant skills, maintainer identities, funding setup, sponsor sales claims, remote metrics scripts, deployment credentials and website are not carried into the new application. The upstream README is retained only as a clearly labelled archival source document.
